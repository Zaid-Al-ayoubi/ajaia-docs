# AI-Native Workflow Note

## Tools Used
- **Claude / ChatGPT:** Used for generating the initial boilerplate, API route structures, and writing the TipTap editor components.
- **Cursor / AI IDE:** Used for inline code completions and quick syntax fixes.

## Where AI Materially Sped Up Work
- **UI Components:** Generating the Tailwind CSS classes for the editor toolbar and the dashboard layout.
- **API Boilerplate:** Generating the Next.js Route Handlers (GET, POST, PATCH) and the Prisma queries.
- **Error Resolution:** When hitting the Prisma connection pooling issue and Next.js 16 build errors, AI helped quickly identify the root cause (`pgbouncer=true` parameter and `export const instant = false`).

## What Was Rejected or Changed from AI Output
- **Authentication:** AI initially suggested a full NextAuth setup. I rejected this to save time and implemented a simpler mock-cookie approach, which was more appropriate for this specific demo scope.
- **Database:** AI generated SQLite code first. I intentionally switched this to PostgreSQL/Supabase for the deployment phase to ensure the live URL had persistent storage.

## Verification & UX Quality
- Every API route generated by AI was manually reviewed to ensure it checked for the `ownerId` or `shares` before allowing edits.
- The editor's autosave was tested manually to ensure it didn't spam the API (debounced by 1000ms).
- Test cases were written (and run via `vitest`) to verify the text-to-HTML conversion logic for file uploads.
